# sos_blink 仕様

ソース: [`src/sos_blink/sos_blink.ino`](../src/sos_blink/sos_blink.ino)

## 目的
関数化と `for` 文による繰り返し処理を使い、モールス信号の SOS をLEDで表現する。

## 使用GPIO
- GPIO 18（出力）。配線は [hardware.md](hardware.md) を参照。

## 動作仕様
- 電源投入後、自動的に SOS パターンを繰り返す
- S：短点を3回、O：長点を3回、S：短点を3回 の順に表示する

| 項目 | 定数名 | 時間 |
|---|---|---|
| 短点 点灯 / 消灯 | `SHORT_ON_MS` / `SHORT_OFF_MS` | 200ms / 200ms |
| 長点 点灯 / 消灯 | `LONG_ON_MS` / `LONG_OFF_MS` | 600ms / 600ms |
| 文字間の追加待機（S→O、O→S） | `LETTER_GAP_MS` | 300ms |
| SOS終了後の待機 | `REPEAT_GAP_MS` | 2000ms |

文字間・繰り返し前の待機は、直前の点滅の消灯時間に**追加**される。
そのため実際にLEDが消えている時間は次のとおり。

| 区間 | 実際の消灯時間 |
|---|---|
| S → O | 200 + 300 = 500ms |
| O → S | 600 + 300 = 900ms |
| SOS → 次のSOS | 200 + 2000 = 2200ms |

1周期の合計: 1200 + 300 + 3600 + 300 + 1200 + 2000 = **8600ms**

## タイミングチャート

## 入力

## 出力
- LED（GPIO 18）

## 異常時

## 既知の制約
- `delay()` で待機しているため、点滅中は他の処理（ボタン入力など）を行えない。
  次のステップで `millis()` を使ったノンブロッキング方式に改善する予定。
