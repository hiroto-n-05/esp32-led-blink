## 配線
```
ESP32                                 
GPIO 18 ──[ 330Ω ]──▶|── GND
                    LED
               (アノード)(カソード)
```

| ESP32 ピン | 接続先 |
|---|---|
| GPIO 18 | 330Ω抵抗 → LEDのアノード（足が長い方） |
| GND | LEDのカソード（足が短い方） |

GPIO 18 を `HIGH`（3.3V）にすると電流が流れて点灯し、`LOW`（0V）で消灯する（アクティブHigh）。

## 電流制限抵抗の計算
LEDに流れる電流 I は、電源電圧 V、LEDの順方向電圧 Vf、抵抗 R から次の式で求める。

```
I = (V - Vf) / R
```

| LEDの色（目安） | Vf | 電流 I（V = 3.3V, R = 330Ω） |
|---|---|---|
| 赤・黄 | 約 2.0V | (3.3 - 2.0) / 330 ≒ 3.9mA |
| 白・青 | 約 3.0V | (3.3 - 3.0) / 330 ≒ 0.9mA |

いずれも数mA程度で、ESP32のGPIOが出力できる電流の範囲内に収まる。
Vf は使用するLEDのデータシートで確認すること。

## 補足
- ボード上のLED（IO2）は GPIO 2 に接続されている。最初の練習では GPIO 2 を使用し、
  外付けLEDの配線に慣れるため GPIO 18 に変更した。
