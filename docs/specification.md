# LED点滅プログラム仕様

## 目的
ESP32の基本的なデジタル出力（GPIO）を理解する。

## 使用機材
- ESP32 開発ボード
- USBケーブル
- PC

## 開発環境
- Arduino IDE
- ESP32 Dev Module

## 使用GPIO
- GPIO 2

## 動作仕様
- 電源投入後、自動的にLEDを点滅させる
- 1秒点灯する
- 1秒消灯する
- 上記動作を繰り返す

## 入力
- なし

## 出力
- LED

## 異常時
今回は考慮しない。

## 動作確認条件
- ESP32へ正常にプログラムを書き込めること
- LEDが1秒点灯すること
- LEDが1秒消灯すること
- 点灯・消灯を繰り返すこと
