# led_blink 仕様

ソース: [`src/led_blink/led_blink.ino`](../src/led_blink/led_blink.ino)

## 目的
ESP32のGPIOによるデジタル出力の基本（`pinMode()` / `digitalWrite()` / `delay()`）を理解する。

## 使用GPIO
- GPIO 18（出力）。配線は [hardware.md](hardware.md) を参照。

## 動作仕様
- 電源投入後、自動的に点滅を開始する
- 1000ms 点灯 → 1000ms 消灯 を繰り返す（周期 2秒）

## タイミングチャート
```
        |<-1000ms->|<-1000ms->|
LED  ON  ──────────┐          ┌──────────
    OFF            └──────────┘
```

## 入力
- なし

## 出力
- LED（GPIO 18）

## 異常時
- 今回は考慮しない
